# ❌⭕ Text-Based Tic Tac Toe Game (Python) !!

A simple **console-based Tic Tac Toe game** built using **Python**.  
Two players (**X** and **O**) take turns marking positions on a **3×3 grid** until one player wins or the game ends in a draw.

This project demonstrates basic Python concepts such as functions, loops, condition checking, and user input validation.

---

## 🚀 Features !

- 🖥️ Text-based (console) interface
- 🧑‍🤝‍🧑 Two-player mode (X vs O)
- ✅ Input validation (numbers only, range 1–9)
- 🚫 Prevents overwriting occupied positions
- 🏆 Win detection (rows, columns, diagonals)
- 🤝 Draw detection when the board is full
- 🔁 Replay option after each game
- 📘 Beginner-friendly logic and structure


## 🛠️ Technologies Used !

- Python 3
- Standard Python libraries only



## ▶️ How to Run the Game !

1. Make sure **Python 3** is installed on your system.
2. Open a terminal in the project directory.
3. Run the following command:

```bash
python main.py

🎮 How to Play

The board positions are numbered from 1 to 9:

 1 | 2 | 3
---|---|---
 4 | 5 | 6
---|---|---
 7 | 8 | 9


Player X starts the game.

Players take turns entering a number (1–9) to place their mark.

The game announces the winner or declares a draw.

Players can choose to play again after each round.
